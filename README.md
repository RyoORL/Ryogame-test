# Dice Bluff — ขั้นที่ 1

เกมเว็บเต๋าจับโกหกแบบออนไลน์ รองรับสูงสุด 6 คน

## ต้องติดตั้ง
- Node.js 18+ 

## วิธีรัน
1. เปิด Terminal ในโฟลเดอร์นี้
2. รัน `npm install`
3. รัน `npm start`
4. เปิด `http://localhost:3000`

## ตอนนี้มี
- สร้างห้อง
- เข้าห้องด้วยรหัส
- สูงสุด 6 คน
- ผู้เล่นละ 5 ลูกเต๋า
- ลากลูกเต๋าได้
- เขย่าเต๋า
- คว่ำ/หงายบอร์ด
- เมื่อคว่ำ คนอื่นจะไม่ได้รับค่าลูกเต๋าของเรา แต่เจ้าของยังเห็นของตัวเอง

## ขั้นต่อไป
- ทำ UI ให้เหมือนเกมจริง
- ระบบเริ่มเกม/เทิร์น
- ระบบตรวจการทอย
- ปรับการซิงก์ให้ลื่นขึ้น
- นำขึ้นโฮสต์ออนไลน์ให้เพื่อนเข้าจากมือถือได้
